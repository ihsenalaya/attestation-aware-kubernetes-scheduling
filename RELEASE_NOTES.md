# v1.0.0 — Article 1 research artifact

Reference implementation, archived experimental data, analysis tools, deployment
configuration, and the current working manuscript for *Attestation-Aware
Scheduling for Verifiable AI Placement on SEV-SNP Confidential Kubernetes Nodes*.

This release concerns node-level AMD SEV-SNP placement on AKS. Local kind/KWOK
results are regression data. The manuscript retains its anonymous review status;
no journal acceptance or final author approval is implied.

See `README.md` for reproduction commands and `ARTIFACT_VALIDATION.md` for
validation results and known limitations. `SHA256SUMS` records all packaged files
except itself.
