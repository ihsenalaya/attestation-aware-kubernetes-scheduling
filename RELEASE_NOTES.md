# v1.0.1 — Reproducibility artifact (software and data)

This version distributes the article's software, scripts, configuration and
experimental data. The article manuscript PDF, LaTeX sources and bibliography
are removed from the release contents. Supporting result figures and CSV tables
are retained under `results/reference/` with corresponding path updates.

The implementation and raw experimental measurements are unchanged from v1.0.0.
Metadata, reproduction instructions, provenance and the SHA-256 inventory are
updated for the software/data package. See `ARTIFACT_VALIDATION.md` for checks
and limitations, including unavailable historical logs and redacted MAA tokens.

The original v1.0.0 snapshot remains a separate historical version. This release
changes the contents of v1.0.1; it does not alter previous archives.
